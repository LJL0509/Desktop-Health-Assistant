# v1.0.2 弹窗与重复提醒修复记录

日期：2026-08-14  
版本：`v1.0.2`

## 更新目的

实际使用中发现，姿势提醒底部的“知道了”按钮在当前 Windows DPI 缩放下被窗口边缘裁切。姿势和眨眼提醒还存在持续异常只提醒一次的问题，用户忽略第一次提醒后不会再次收到干预。

## 更新内容

- 弹窗从固定 `420×154` 攑为固定宽度、动态高度；
- Tkinter 完成标题、正文和按钮布局后读取实际所需高度，再定位并显示窗口；
- 设置 180 像素最小高度，保留完整按钮和底部间距；
- 姿势和低眨眼频率首次报警后，异常持续 3 分钟再次提醒；
- 第二次提醒后异常仍持续，改为每 10 分钟提醒一次；
- 恢复正常后清空重复提醒计划；
- 低眨眼频率的重复间隔按有效观察时间计算，识别不到脸时暂停。

## 验证结果

- 姿势提醒真实文案在当前 DPI 环境下完整显示；
- 眨眼提醒真实文案在当前 DPI 环境下完整显示；
- 两个弹窗的“知道了”按钮均可完整看到；
- 姿势重复提醒和恢复重置测试通过；
- 眨眼重复提醒、恢复逻辑和脸部缺失暂停计时测试通过；
- 138 项自动测试全部通过；
- Python 编译检查和 `git diff --check` 通过。
