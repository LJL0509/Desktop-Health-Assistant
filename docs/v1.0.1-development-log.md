# v1.0.1 软件化与发布记录

日期：2026-08-14  
版本：`v1.0.1`

## 更新目的

`v1.0.0` 已经形成监测、提醒、日报和托盘闭环，但仍依赖项目源码、Python 虚拟环境和手动启动。`v1.0.1` 的目标是把这些功能整理为普通 Windows 用户可以解压、双击并长期运行的软件，同时保证摄像头画面不保存、不上传。

## 更新内容

- 使用 PyInstaller 生成一目录 Windows 应用，包含 Python 运行时、MediaPipe、模型、OpenCV、Tkinter 和通知依赖；
- 增加正式应用图标、EXE 版本信息、便携包构建脚本和 Inno Setup 安装器配置；
- 打包模式从应用资源目录读取模型，运行数据写入当前用户的 `%LOCALAPPDATA%`；
- 增加文件日志、顶层异常保护和 Windows 错误提示；
- 增加开机自动启动、打开数据目录、DPI 感知和打包模式重复启动提示；
- 保留开发模式原有目录和启动方式，不迁移或覆盖已有项目数据。

## 调试过程

第一次打包排除了 Matplotlib，MediaPipe 导入时因此失败，恢复 Matplotlib 后解决。第二次启动发现 MediaPipe Tasks 会动态加载 `mediapipe.tasks.c.libmediapipe.dll`，随后在 spec 中显式收集 MediaPipe 动态库并加入 `mediapipe.tasks.c` 隐式导入。修正后，打包程序成功加载模型并打开摄像头。

便携包生成后被解压到新的临时目录，以独立的数据目录启动 `--no-camera` 模式，确认程序不依赖源码目录。完整摄像头模式也完成了实际启动、MediaPipe 加载、监测会话创建和持续运行检查。

## 验证结果

- 132 项自动测试全部通过；
- 所有 Python 脚本编译通过；
- `pip check` 未发现损坏或冲突的依赖；
- `git diff --check` 未发现补丁格式错误；
- EXE 文件属性显示产品名称“桌面健康助手”和版本 `1.0.1`；
- 打包程序成功加载模型、MediaPipe 动态库和摄像头；
- 全新解压的便携包可以独立启动；
- 用户实际测试后确认当前表现符合预期。

## 发布边界

本版本提供 64 位 Windows 便携包。安装器配置已经完成，但由于当前电脑没有安装 Inno Setup，本次未生成安装向导。程序尚未购买代码签名证书，因此其他电脑首次启动时可能遇到 Windows SmartScreen 提示。
