# v1.0 开发与定版记录

版本：`v1.0.0`

日期：2026-08-12

## 1. 定版目标

本版不再增加检测类型，而是把已有能力整理成可以日常运行的完整闭环：

1. 用户完成一次个人正常坐姿与睁眼联合校准；
2. 程序持续观察头部前倾、头部过低和眨眼；
3. 问题持续达到时间阈值后再提醒；
4. 补水通知同时承担离屏活动提醒，凌晨 1 点提供作息提示；
5. 只记录数值事件和持续时长，跨日自动生成健康报告；
6. 用户通过系统托盘控制长期运行的程序。

## 2. 托盘控制

托盘菜单包含：

- 隐藏或恢复监测窗口；
- 暂停或继续摄像头监测；
- 打开最新日期的 Markdown 报告；
- 正常退出程序。

隐藏窗口只影响显示，监测继续运行。暂停监测会释放摄像头，便于视频通话等程序使用。托盘线程只修改线程安全的控制状态，摄像头、OpenCV 窗口和 MediaPipe 模型仍由监测主线程管理。

## 3. 校准规则

- 按 `C` 后准备 3 秒；
- 正式采集至少 10 秒；
- 姿势和眼睛各至少需要 30 个有效样本；
- 样本不足时最长采集 20 秒；
- 校准不会定时重复，重启程序或环境明显变化后由用户重新按 `C`；
- 隐藏窗口、暂停后恢复和跨午夜不会主动覆盖个人基线。

## 4. v1.0 功能边界

本版已经完成：

- 头部前倾与整个身体靠近的相对判断；
- 头部过低和数据不足提示；
- 眨眼、快速眨眼、持续闭眼和低频提醒；
- 补水、离屏活动和凌晨 1 点睡眠提示；
- Windows 空闲时间估算的连续使用统计；
- JSON 与 Markdown 每日报告；
- 单实例、摄像头暂停释放和系统托盘控制。

以下内容明确延期，不应从现有报告中推断：

- 屏幕距离是否过近；
- 固定姿势持续时间；
- 完整圆肩识别；
- 真实久坐和真实饮水行为。

## 5. 验证结果

- 111 项自动测试通过；
- Python 编译检查通过；
- Python 依赖完整性检查通过；
- 真实 Windows 托盘线程启动和后台退出通过；
- 托盘退出会正常结算连续使用事件；
- 完整摄像头统一入口可以持续运行；
- 使用真实日志成功生成日报，已有报告不会被自动覆盖；
- 摄像头画面不保存、不上传。

## 6. 已知限制

- 头部前倾仍可能受服装轮廓、画面裁切和座椅位置变化影响；
- 极快眨眼可能完整落在相邻采样之间；
- 连续使用来自键鼠空闲时间估算，看视频或阅读可能被误认为离开；
- 产品阈值用于行为提示，不是医学诊断阈值；
- 目前只在一名用户和一台 Windows 11 笔记本上进行主要验证。

## 7. 后续版本原则

`v1.0.0` 发布后不再直接修改本版检测参数。真实日常使用中发现的问题先记录，再按影响程度进入 `v1.0.x` 修复版或 `v1.1.0` 功能版。
