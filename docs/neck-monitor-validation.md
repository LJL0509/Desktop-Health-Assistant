# 脖子前倾持续监控验证

验证日期：2026-08-10

## 验证版本

- 个人正常坐姿校准 15 秒；
- 最近 5 秒窗口使用中位数；
- 脸宽增长和脸宽/虚拟肩宽比例增长均达到 8% 时形成前倾候选；
- 候选连续保持 3 秒后切换状态；
- 脖子系统只输出 `NECK NORMAL` 和 `NECK FORWARD`；
- 整体靠近不计为脖子异常；
- 数据连续不足 10 秒后提示检查位置。

## 人工反馈结果

| 项目 | 结果 |
| --- | ---: |
| 反馈总数 | 25 |
| 判断正确 | 23 |
| 判断错误 | 2 |
| 人工反馈准确率 | 92.0% |

两次错误均为用户认为发生前倾，但程序仍显示正常：

1. 脸宽增长约 3.3%，比例增长约 3.6%，明显低于当前实验阈值；
2. 脸宽增长约 7.9%，比例增长约 16.6%，脸宽刚好低于 8% 阈值。

日志中同时存在短暂超过增长条件但被用户确认正常的样本，因此本轮不降低阈值，避免增加误报。较轻的头部前移可能仍无法稳定识别。

## 数据不足提醒

| 项目 | 结果 |
| --- | ---: |
| 持续 10 秒提醒 | 3 次 |
| 恢复后自动清除 | 3 次 |

三次提醒原因均为虚拟肩部锚点未保持在下巴下方，提示内容为 `TOO CLOSE OR BENT TOO LOW`。提醒持续时间分别约为 17.9 秒、12.1 秒和 14.7 秒，恢复有效画面后均自动清除。

## 当前结论

- 二态脖子分类比多状态距离/姿势混合分类更符合实际需求；
- 5 秒平滑与 3 秒状态确认减少了阈值附近的闪烁；
- 8% 个人实验阈值暂时保留；
- 数据不足提醒逻辑通过本轮验证；
- 下一阶段应进行更长时间的自然使用，而不是继续用刻意动作反复调参。
