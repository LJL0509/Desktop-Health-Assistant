# Desktop Health Assistant

本地运行的桌面健康助手。项目使用摄像头和个人姿势校准，观察长期使用电脑时的脖子前伸状态。摄像头画面只在内存中处理，不保存、不上传。

当前版本：`v1.0.3`，可直接分发的 Windows 版本。核心监测、提醒、日报、托盘控制和应用打包已经形成完整闭环。

## v1.0.3 功能

- 一次完成正常坐姿与睁眼基线的联合校准；
- MediaPipe Face Landmarker 与 Image Segmenter；
- 肩膀离开画面时仍可使用脸部和可见上身轮廓；
- `PARTIAL`、`FULL`、`TOO LOW` 和数据不足状态；
- 正常、头部前伸、整体靠近和整体远离动作区分；
- 最近 2 秒中位数和 2 秒状态确认；
- 头部前伸连续 60 秒后才提醒，短暂动作不报警；
- 头部过低的独立提示；
- 暂停时释放摄像头；
- 本地记录事件、持续时长和人工正确/错误反馈；
- 不把屏幕距离直接解释为脖子姿势；
- 默认每 60 分钟发送一次“补水与休息提示”，点击“已喝水”后重新计时；
- 每天凌晨 1 点弹出睡眠提示；
- 使用 Windows 键鼠空闲时间估算连续电脑使用时长；
- 连续 5 分钟无输入后结束当前使用段，不单独发送固定时长休息通知；
- 汇总姿势、监控覆盖、连续使用、补水和睡眠提醒，生成每日 JSON 与 Markdown 报告；
- 一个统一启动入口，可选择是否开启摄像头；
- Windows 单实例保护，阻止重复提醒和重复统计。
- 左右眼几何开合度与 MediaPipe blendshape 联合眨眼识别；
- 普通眨眼、快速高置信眨眼和持续闭眼区分；
- 最近 5 分钟有效观察低于 15 次/分钟时提醒，恢复到 18 次/分钟后解除低频状态；
- 面部缺失、摄像头暂停和校准期间不计入有效眼部观察；
- 上身分割移至后台线程，避免姿势分析阻塞眨眼采样；
- 每日报告汇总眨眼数、有效观察时长、平均频率、低频提醒和持续闭眼。
- 跨过午夜时自动结算前一天数据并生成日报；
- 第二天首次启动时自动补生成缺失的昨天报告；
- 已存在的自动报告不会被重复覆盖；
- 无有效监测数据时明确显示“无法评价”，不解释为健康正常。
- 系统托盘支持隐藏或恢复监测窗口、暂停或继续摄像头、打开最新报告和退出；
- 隐藏窗口不会停止监测，暂停摄像头时会真正释放设备。
- 可直接解压运行的 64 位 Windows 便携版，不要求用户安装 Python 或 MediaPipe；
- 应用图标、文件版本信息、异常日志、用户数据目录和开机自动启动控制；
- 打包后模型与程序资源独立于源码目录，用户数据保存在 `%LOCALAPPDATA%\Desktop Health Assistant\data`。
- 姿势和眨眼弹窗按实际内容自动调整高度，适配 Windows DPI 缩放；
- 持续异常在首次提醒后 3 分钟再次提醒，此后每 10 分钟提醒，恢复正常后重置计时。
- 头部前倾与头部过低无缝切换时延续异常计时，低头连续 60 秒后提醒；
- 全屏游戏和浏览器视频中使用不抢焦点的分层置顶弹窗，不退出全屏或唤出任务栏。

## Windows 便携版

解压 `release/DesktopHealthAssistant-Portable-1.0.3.zip` 后，双击 `DesktopHealthAssistant.exe`。必须保留同目录下的 `_internal` 文件夹。首次使用时允许摄像头权限，并按 `C` 完成个人正常姿势与睁眼基线校准。

程序未经代码签名，Windows SmartScreen 可能显示“未知发布者”。当前发布目标为 64 位 Windows 10/11。

## 环境

- Windows 11
- Python 3.11
- MediaPipe 1.0.0
- 内置摄像头，优先使用 Media Foundation 共享接口

## 首次运行

```powershell
cd D:\Github\Desktop-Health-Assistant
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe scripts\download_models.py
.\.venv\Scripts\python.exe scripts\desktop_health_assistant.py
```

默认启动完整摄像头监控。只运行补水、睡眠提醒和连续使用统计，不开启摄像头：

```powershell
.\.venv\Scripts\python.exe scripts\desktop_health_assistant.py --no-camera
```

两个模式不能同时运行；如果重复启动，第二个进程会提示助手已在运行并退出。

完成首次环境安装后，也可以直接双击项目根目录中的：

- `start-camera.bat`：启动完整摄像头监测；
- `start-no-camera.bat`：只启动提醒和连续使用统计。
- `test-health-popup.bat`：等待 5 秒后测试全屏窗口中的健康提醒。

生成当天健康报告：

```powershell
.\.venv\Scripts\python.exe scripts\daily_report.py
```

报告保存在 `data/reports/`。也可以使用 `--date 2026-08-12` 生成指定日期报告。

## 操作

- `C`：开始正常坐姿校准；
- `P`：暂停并释放摄像头，再按一次恢复；
- `Y`：标记当前判断正确；
- `N`：标记当前判断错误；
- `W`：可选的手动喝水记录；日常使用也可直接点击系统通知中的“已喝水”；
- `Q` 或 `Esc`：退出。

右下角系统托盘菜单还可以隐藏或恢复监测窗口、暂停或继续摄像头、打开最新报告以及退出程序。隐藏窗口与暂停摄像头不同：隐藏后仍在监测，暂停后摄像头会被释放。

## 当前判定逻辑

程序比较当前脸部和可见上身轮廓与个人健康基线之间的变化：

- 脸部与上身同步缩放时，视为整个身体靠近或远离，脖子仍判断为正常；
- 脸/上身比例、相对尺度和垂直位置共同偏离时，判断为头部前伸；
- 头部过低、轮廓严重缺失或信号矛盾时，显示独立提示或数据不足，不猜测为正常；
- 健康基线只由用户按 `C` 校准产生，运行中不自动学习新姿势；
- 屏幕距离与脖子姿势是两个独立系统。

姿势参数和 60 秒提醒时长来自个人原型验证，是产品默认值，不是医学标准。

## 限制

- 不是医疗设备，不诊断颈椎病、圆肩或其他疾病；
- 目前仅基于一名用户和一台内置摄像头验证；
- 舒服坐姿下上身轮廓明显变窄时，可能误报头部前伸；
- `PARTIAL` 与 `FULL` 边界会受衣服、画面裁切和坐姿影响；
- 摄像头位置、屏幕角度或座椅明显变化后需要重新校准；
- 补水功能只统计用户确认的记录，不能判断未确认期间是否实际喝过水；
- 报告可自动生成，但目前仍没有图形化历史报告浏览界面；
- 连续使用由键鼠空闲时间估算，看视频或阅读时可能把无输入误认为离开；
- 连续电脑使用不等于真实久坐，程序不知道用户是否站立；
- 极快眨眼可能完整落在相邻采样之间而漏记；
- 15 次/分钟和恢复阈值 18 次/分钟是当前个人产品默认值，不是统一医学危险阈值；
- 固定姿势和屏幕距离尚未接入报告。
